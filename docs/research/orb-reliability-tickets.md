## Architecture ground truth (shared by all tickets)

- The **bridge runs on the host**; it shells out to host `git`/`gh`/`docker` via injectable seams. The orb's clone lives in a Docker volume (`orb-<id>-workspace` at `/workspace` in-container) — the bridge **cannot** read the volume's git directly, but **can** shell `git ls-remote <remote> <ref>` against the remote (pattern already in `OrbService.seedBranch`, orb_service.dart ~677–709).
- **Per-orb single branch**: `branch = 'orb/$id'` minted once in `OrbService.create` (orb_service.dart ~527–666, line ~543), persisted as Docker label `ocb.branch` (container + both volumes), re-read at wake/update via `orb_record_composition.dart`. `OrbService.git` (public field, ~441) is the `GitRunner` seam; `OrbTaskService` holds a public `orbs` reference (`orb_task_service.dart:125`).
- **Spawn flow**: TS plugin `orb_spawn` (embedded in `orb_agent_tools.dart`) → `POST /api/orb/spawn` → `BridgeServer._handleOrbSpawn` (bridge_server.dart ~3199–3265) → `OrbTaskService.spawn` (~275–317, per-project gate `_spawningByProject` ~290–313) → `_spawnLocked` (~319–423) → `_targetOrCreateOrb` (~547–606) → wake/create → `createSessionOnOrb` → `OrbTask` built (~391) → `prompt`. Idempotent retry: `_retriedTaskOn` (~503–523) — first match, same text/dispatch-id.
- **Completion settle path (single)**: `OrbTaskService._check` (~989–1066) reads the orb session outcome → `_settle` (~1095–1135): sets status/summary, `pr = await _prUrl`, `completed`. Delivery: `_deliverCompletion` (~1204) → `_injectInto` (~1277, in-app message) + fallback `_pushCompletion` (~1301, FCM). Artifact list = `OrbTask.results` getter (orb_task.dart:145: `['branch: $branch', if (pr) 'PR: $pr']`).
- **Post-commit auto-push**: NOT a repo hook — generated by the entrypoint (const `_entrypoint` in `orb_embedded.dart`, install ~309–331, refspec `git push origin HEAD:refs/heads/orb/${ORB_ID}` at ~320–325, `push-failed` marker on failure feeds `OrbRecord.pushFailing`).
- **Image**: no Dockerfile in the repo. Embedded `_dockerfile` const in `orb_embedded.dart` (~33–181): toolchains are `ARG` defaults (lines ~46–56: NODE 22.14.0, NPM 10.9.2, PHP 8.3, FLUTTER 3.47.8, REDIS 7.4.0, POSTGRES 16, TYPESENSE 28.0, MAILHOG 1.0.1, GIT 2.43, OPENCODE 2.2.7, GH 2.103.3) with a `RUN … grep -q …` enforcement block (~167–178). Materialized by `OrbBuildContext.materialize` (`orb_build_context.dart:66`), tag = content hash of the whole context. The embedded Dockerfile is the single source of truth as shipped.
- **Plugin digests**: the embedded TS plugin digest is tracked in `orb_agent_tools.dart:53–69` (`previousDigests`) — editing the plugin const means stale installs only refresh if the new digest is reachable; existing tests use `stale_plugin_v1_fixture.dart`.
